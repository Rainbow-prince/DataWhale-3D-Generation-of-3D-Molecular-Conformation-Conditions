# DataWhale-3D-Generation-of-3D-Molecular-Conformation-Conditions
参加DataWhale的组队学习中，参加第三届世界科学智能大赛材料设计赛道：3D分子构象条件生成。本仓库记录自己的学习经历

**本题任务是设计分子的3D结构**。分子的3D结构决定了其性质，反过来说，如果需要分局具有什么样的性质，那么就要从结构上入手。传统方法通过实验、理论计算等手段来获取分子结构数据，这需要投入大量时间和计算资源，成本和复杂性都很高，所以，分子结构数据往往存在严重匮乏的现象。

这道题就是要生成合理的的3D分子结构，助力药物研发、催化剂设计、以及新能源材料开发
- 初赛要求结构合理
- 复赛要求分子结构要符合特定的性质

---

### 1.2 这个任务是典型的什么问题？

**这个任务是典型的生成问题**。通过训练集训练AI生成式模型，在该模型的基础上，生成1万个分子的3D结构。


---

### 1.3 输入与输出是什么？

#### 输入数据：
分子构象数据：格式为`.pkl` ，由一个包含若干训练样本的list构成，每个样本包含一个dict

| 字段          | 中文名                   | 数据类型              | 说明                                                          |
| ----------- | --------------------- | ----------------- | ----------------------------------------------------------- |
| natoms      | 原子数量 number of aatoms | int               | 表示当前样本总共的原子数量                                               |
| elements    | 原子元素种类                | List[str]         | 描述当前样本的组成原子种类，第i个元素表示第i个原子的元素种类                             |
| coordinates | 原子坐标                  | List[List[float]] | 描述当前样本每个原子的3D位置，顺序与elements的value对应，第i个元素表示第i个原子在笛卡尔坐标系中的坐标 |
| properties  | 化学性质                  | List[float]       | (复赛提供) 描述当前样本的绝对能量，数值经过脱敏处理。                                |


---


|     | 样本数量  | 元素种类                        | 单分子最大构象数量 |
| --- | ----- | --------------------------- | --------- |
| 初赛  | 4-5 万 | C, H, O, N, F, P, S, Cl, Br | 1         |
| 复赛  | 4-5万  | C, H, O, N, F, P, S, Cl, Br | 1-4       |
- 单分子最大构象数量：
	- 初赛数据：
		- 每个分子仅含 1 种构象。或者说，一种分子，只有一个“长相”
		- 例如，某水分子（H₂O）的结构固定为一种确定的三维坐标排列，***不会因扭曲或旋转而产生不同的构象记录***。
	- 复赛数据：
		- 每个分子可能包含 1 到 4 种构象。
		- 例如，某丁烷分子（C₄H₁₀）可能***因其碳链的旋转异构（如反式、顺式等）产生不同的空间排列***，在复赛数据中被记录为最多 4 种不同构象

---

#### 输出数据

- 文件格式要求：
	- 文件格式：pkl
	- 10000个分子的3D结构，所有分子数据存在一个列表中，每个分子表示为一个dict类，具有三个key：'natoms', 'elements', 'coordinates'
		- `'natoms'`: int. # example: 46
		- `'elements'`: list\[str\] # example: `['C', 'H', 'O']`
		- `'coordinates'`: list\[list\[float, float, float\], list\[float, float, float], ...\] # example: `[[1.2, 0.5, -0.2], [0.54, -0.41, 1.45]]`
	- 提交文件名：output.pkl（亲测似乎无要求）

- 生成的分子的要求：
	- 分子大小的分布，各元素出现频率的分布须与给定数据集一致；
	- 生成最大的分子的原子数不允许超过60，否则会影响最终提交结果及分数
